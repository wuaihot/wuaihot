# 观赛平台标识来源

此目录的 `youtube.svg`、`twitch.svg` 和 `wechat.svg` 取自 [Simple Icons](https://simpleicons.org/) 项目的相应平台图标（2026-10-11 下载，经 SVG 内容和 24×24 视图框验证），使用官方平台的品牌配色，作为赛事观赛入口的品牌识别。相关品牌名称与标识属于各自权利人；参考项目：[Simple Icons GitHub](https://github.com/simple-icons/simple-icons)。

Bilibili、虎牙、腾讯、微博直接复用站点现有 `public/logo/` 资源，不另行维护重复版本。
